Project Summary

The Problem

Live sports betting is dominated by centralized platforms that control odds, lock markets unpredictably, and require full custody of user funds. There is no way for users to bet transparently while watching a live stream — every existing solution forces users to leave their viewing experience.

Our Solution

Goal.Live is a Chrome extension that injects a real-time betting overlay directly onto any live football streaming page. Users connect MetaMask, deposit USDd tokens on Hedera Testnet, and place bets without ever leaving their stream. All funds are escrowed in a Solidity smart contract deployed on Hedera's EVM — no custodian, no intermediary.

Key Differentiators

🎮 Non-Intrusive UX

Overlay works on any streaming page — YouTube, Twitch, any football stream. No separate app needed.

🔒 Non-Custodial

Funds locked in smart contracts on Hedera. Users hold keys. No intermediary can freeze or seize funds.

⚡ Gasless Betting

Platform relayer pays gas for bet recording. Users only pay gas for deposit and withdrawal — 2 MetaMask txs total.

Key Learnings

🔗 Hedera EVM Compatibility

Hedera's EVM via HashIO provides near-seamless Solidity deployment. The same contract that runs on Sepolia deploys identically on Hedera — enabling true multi-chain development from a single codebase with Vite aliases.

⚡ Hybrid Architecture Works

Combining Supabase (instant, gasless UX) with on-chain settlement (trustless finality) gives the best of both worlds. Users get web2-speed interactions with web3-grade security.

🧩 Build System Matters

Vite's alias system enabled building Sepolia and Hedera extensions from the same source code — swapping only network config and wallet bridge at build time. This pattern scales to any EVM chain.

🎯 MVP Scoping

Focusing on a single bet type (Next Goal Scorer) let us deliver a complete, working end-to-end flow rather than a half-finished multi-feature product. The architecture supports additional bet types without contract changes.

Room for Improvement

  • Oracle automation — Chainlink CRE workflow is architected but not yet deployed on DON
  • Row-Level Security — Supabase RLS policies need hardening
  • Mobile experience — extension is desktop-only; mobile app planned
  • Gas optimization — batch settlement could reduce per-user gas costs
  • UI polish — enhanced animations, match timeline, bet history
